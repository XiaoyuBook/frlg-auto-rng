# FRLG Auto RNG 0.9.3 PySide6版

同步最新 2.0 正式脚本，并增加 Gitee 分卷备用更新与更新源选择。当前修正版内部版本码为 `2026092001`。

- 修复打包版 TID 连续流程因标准输出句柄失效而出现 `OSError: [Errno 22] Invalid argument` 并连锁崩溃；普通/孵蛋日志运行器同步容错。控制台不可用时仍保留文件日志、实测记录、续跑进度和真实退出码，不忽略真正的日志文件写入错误。
- 修复日版火红/叶绿 Switch 2 在 TID 成功后无法生成御三家目标的问题：补齐版本白名单和日版 Seed 表映射，保留 Switch 2 机型参数；覆盖任意 TID、不乱数 SID 和已知 TID/SID 接续。
- 普通和孵蛋 HOME_BUFFER 按 NS1/NS2 选择对应标签，保留工具的延迟画面确认与锁定保护；补齐孵蛋 NS2 退出识别。
- 同步英日 TID 连续脚本的机型标签选择、关闭游戏及 HOME_BUFFER 有限重试、50ms 调整和失败停止。可选低分自适应保留新脚本的重试上限与返回值检查。
- 同步狩猎区第 0 轮 Teachy TV 的 1000ms 启动保护，并从固定延迟测量中扣除该等待；后续轮次仍使用原等待参数。
- 同步 Seed 表设置预检与方案 2 日志；导入时排除 Seed 表历史备份，固定预校准默认值保持不变。
- “设备与运行”可选择自动（GitHub 优先）、GitHub 或 Gitee 更新源。自动模式在 GitHub 检查或网络下载失败时尝试 Gitee；手动模式仅使用指定来源。
- Gitee 使用同一完整 ZIP 的分卷，每卷与合并结果都校验大小及 SHA-256，备用源不会跳过 TLS 或版本校验。
- 野生土龙弟弟增加“可进化为三节形态（土龙节节）”筛选，默认关闭，仅筛选目标 PID。

完整解压 `FRLG-Auto-RNG-0.9.3-windows-x64.zip` 后运行 `FRLG-Auto-RNG.exe`。升级后重新生成方案；旧生成脚本不会自动修改。配置、存档资料、日志、进度、Seed 表和设备标签覆盖仍保存在 `%LOCALAPPDATA%\FRLG-Auto-RNG`。

Gitee 发布需上传 `gitee-release-assets` 内全部分卷和 `gitee-update-manifest.json`，并使用同一 `v0.9.3` 标签。旧版若因证书问题无法更新，请手动下载一次。

正式运行时仍为 EasyCon `1.6.4-a+9c86137`。不包含 170a 实验后端；软件及编译验证不替代实机验收。
